## Table of Contents
A fast food website platform that provides a seamless interface for users to explore menu items and access vital information. Built with modern web technologies and focused on delivering an engaging user experience.

## Features

- **Dark/Light Mode Toggle** - Customizable viewing experience
- **Responsive Design** - Optimized for all device sizes
- **Interactive Menu** - Dynamic menu display with Swiper.js integration
- **User Authentication** - Secure login and signup functionality
- **Order System** - Integration with food delivery platforms
- **Smooth Animations** - Enhanced UX with Scroll Reveal
- **Database Integration** - MongoDB backend for data persistence

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Fastfood_Website_Static.git
```

2. Install dependencies:
```bash
npm install
```

3. Configure MongoDB:
   - Open `index.js`
   - Replace `<connection link>` with your MongoDB connection string

4. Start the server:
```bash
nodemon index.js
```

5. Access the website:
   - Open your browser
   - Navigate to `http://localhost:5500`

- `GET /` - Main page redirect
- `GET /s` - Signup page redirect
